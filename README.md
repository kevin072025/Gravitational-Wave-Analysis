## Gravitational Wave Detection and Analysis (GW 170814)

A comprehensive analysis of Gravitational Wave data from the LIGO-Virgo Observatories, of the first Gravitational wave signal ever detected.
The pipeline includes pre-processing methods to extract the hidden signal from noise, such as Spectrograms, Q-Transforms, Whitening, and Fourier Analysis.
Techniques such as Matched Filtering are used to pinpoint the exact time of the Black Hole Merger. 
Using Bayesian inference to estimate the parameters, such as chirp mass and mass ratio of the merger black holes. 

## Features:
- Using PyCBC, gwpy, and gwosc libraries to obtain data strains.
- Signal Analysis in the time domain.
- Spectrogram, Q-Transform.
- Matched Filtering.
- Parameter estimation.
- Plots accompanying each feature.
